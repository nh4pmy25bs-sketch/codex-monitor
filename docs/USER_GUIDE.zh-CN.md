# Codex 监控台 1.2

一个在你电脑上运行的私有监控工具。支持 Windows 10 / 11（64 位）。

## 开始使用

1. 完整解压 Windows 发布包后，双击 `CodexMonitor.exe`。
2. 软件会打开本机浏览器界面，同时保留一个小的服务窗口。
3. 点击“连接服务器”，填写服务器地址、SSH 用户名，以及 SSH 密码或本机私钥路径。
4. 首次连接时会展示服务器指纹。与服务器已有的 SSH 指纹核对后，勾选信任并再次连接。
5. 连接后自动同步。你仍然在原来的服务器终端里使用 Codex。

SSH 用户名和密码是你登录服务器使用的信息，与 Codex 的官方账号不同。软件无需读取 Codex 登录凭据，也不需要你提供 OpenAI API Key。

服务器支持 Linux / macOS，需安装 Python 3。查看当前项目差异还需要 Git。此版支持直连 SSH、密码、私钥、可用的 SSH agent，以及 Tailscale 网页认证与系统 OpenSSH 连接；不解析 SSH config 别名，不支持跳板机和普通 SSH 的交互式多因素认证。

通常留空 Codex 数据目录即可（默认 `~/.codex`）。如果服务器设置了自定义 CODEX_HOME，请填写实际绝对路径。目录应属于正在运行 Codex 的同一个服务器用户，包含 sessions 子文件夹。远程非交互式 SSH 环境不一定继承交互式终端的环境变量。

## Tailscale 直接网页登录（1.2）

连接设置里有“打开 Tailscale 登录”按钮，直接打开官方登录页面，由你在浏览器里完成登录。软件不检测本机 Tailscale 是否登录，也不会运行 tailscale login、更换账号或修改本机客户端设置。网页登录不会自动配置本机 Tailscale 客户端，服务器连接沿用你现有的网络。

填写服务器地址和服务器原用户名，点击“连接服务器并处理认证”。如果服务器要求额外验证，软件将打开该次连接返回的专用认证链接，等待你验证后继续；已有授权时直接连接，不额外打开认证页面。Tailscale SSH 使用 22 端口，无需 SSH 密码或 +password。

服务器身份仍需通过已保存的主机密钥校验；首次未知主机需要你核对指纹。认证链接只保留在内存，自动打开仅接受 HTTPS 的 login.tailscale.com/a/ 专用链接。服务器访问权限由你现有的 Tailscale 规则决定。

1.2 的 Tailscale 连接使用 Windows 系统 OpenSSH，并保持一个持久连接读取记录。连接阶段和后台补齐阶段分开显示；首批先取 512 KB，后续分批读取。同步间隔可设置 5 / 10 / 30 / 60 秒。历史数据较多时可先查看已同步内容。

## 密码查看与完成通知（1.2）

- 普通 SSH 密码框右侧可点击“显示 / 隐藏”。关闭连接窗口或切换登录方式后恢复隐藏；密码仍不写入磁盘。
- 右上角铃铛里可开启 / 关闭“Codex 每轮对话完成时，在本机通知”，并发送测试通知、查看最近通知记录。默认开启。
- 服务器同一用户在 VS Code 集成终端运行 Codex，只要记录保存在所连接的 Codex 数据目录，也会收到提醒。
- 通知以明确的每轮完成事件为依据。开始监控之前的历史完成记录不会弹出；同一事件不会重复通知。补齐历史时另外读取最新完成事件，避免通知等待整个历史文件读完。
- 请保持监控台后台服务运行。浏览器可关闭，退出软件后不再监控。通知延迟受所选同步间隔和网络影响。
- Windows 勿扰或系统通知设置可能隐藏弹窗；软件的通知记录仍可查看。通知只包含项目名与完成状态，不包含对话回复正文。

## 四个页面

- 总览：最近会话、今日和累计 token、已应用文件数量、采集状态。
- 会话记录：已保存的输入、回复、命令、工具输出和文件补丁；支持搜索及来源筛选。
- Token 用量：每日图表、输入 / 缓存 / 输出、CSV 导出。日期按北京时间统计。
- 文件变更：成功补丁、修改提议、失败记录；可读取项目当前的 Git 状态与文本差异。

还可以从连接设置中读取本机 Codex 目录，或导入 JSONL 会话记录 / `codex exec --json` 输出。

“先体验演示”使用独立的示例数据，不会写入真实统计。

## 统计范围和准确性

- 这是 Codex 已保存记录的可视化查看器，不是终端屏幕直播。未保存的输出、输入草稿、部分重连与批准提示不一定能看到。
- 默认采集近 30 天有更新的会话文件（含归档），可在设置中扩大范围。这里按文件更新时间筛选，因此一个长会话可能带入更早日期的事件。
- 每次最多扫描最新 2000 个文件；较大的记录分批读取。界面会显示尚未同步完毕、范围限制或格式异常。
- 支持常见 session_meta / response_item / event_msg / token_count 记录，以及 exec JSONL 的 item.* / turn.*。内部日志格式可能随 Codex 版本变化，不兼容格式或无用量记录会导致数据缺失；不会猜测缺失用量。
- 以累计 token 的增量统计，重复同步、重复 token 更新不会重复计数。首次累计值已包含未知历史时，只计本次可确认的用量。缓存输入包含在输入中，推理 token 包含在输出中，不重复相加。
- 这是被采集会话的用量，不等于官方账号剩余额度、官方账号全部使用量或费用。换登录用户、换服务器名 / IP，可能被识别为不同来源；不要把同一批日志用不同来源重复汇总。
- 导入的 exec 输出没有时间戳时，用文件 / 导入时间归档，并标记日期来源；不会伪造历史日期。不同内容的导入文件会作为独立来源。
- 模型分组按会话最后记录模型归类；会话里切换模型不能在此分组精确拆分。
- 任务是否还在运行取决于最后可见事件。超过 3 分钟没有新事件的运行记录会显示“状态未知”，不宣称任务完成。
- 文件“已应用”要求有可确认的成功结果。通过 shell、脚本、其他工具修改的文件不一定有补丁记录。项目当前差异展示整个工作目录相对 HEAD 的变化，包含已暂存 / 未暂存变更；未跟踪文件只列文件名。它不能证明修改由某个会话产生。
- 会话详情最多展示最近 800 条事件，文件页最多展示最近 500 条补丁。单条事件显示内容最多约 15 万字符，项目差异最多展示 1 MB。

## 私有存储和退出

软件只监听本机 127.0.0.1，不发布网站，不接入第三方监控平台，也不开放服务器新端口。服务器上的采集代码通过 SSH 内存执行，不上传文件、不安装服务。Git 使用禁用可选锁的读取模式，不执行项目提供的外部 diff 工具。

SSH 密码和私钥口令只存在本次运行内存中。完成通知偏好保存在 data/settings.json，已通知事件保存在本机数据库。连接地址、用户名、私钥路径和已信任服务器指纹保存在软件目录的 data 文件夹；Codex 的登录凭据不会被读取。

会话内容可能含你自己的代码和工作信息，保存在 `data/monitor.db`。备份整个 data 文件夹即可保存历史。不要把含真实记录的 data 随意分享给别人。

关闭浏览器不停止采集；服务窗口的 × 会最小化并继续后台运行。在小的服务窗口中选择“退出软件并停止同步”才会退出。退出后不再采集，服务器上 Codex 自己保存的日志仍存在，下次连接时增量补齐。此版不在服务器后台独立保留文件历史快照。

卸载时退出软件，删除本软件文件夹和桌面快捷方式即可；如不需要保留监控历史，可一并删除本软件自己的 data 文件夹。

## 源码与验证

仓库包含完整源码与测试。源码基于 Python 标准库、Paramiko、原生 HTML/CSS/JavaScript；Windows 包含所需运行时，无需自行安装 Python。

从源码运行：安装 requirements.txt 中的依赖，然后 `python main.py`。测试：`python -m unittest discover -p "test_*.py" -v`。构建：先安装 requirements-build.txt，然后运行 build.ps1。

已在本机验证增量读取、中文分段、重复同步去重、累计计数重置、跨日统计、补丁成功 / 失败、缺失用量、Git 已暂存和未跟踪文件、SSH 指纹和密码认证、本机接口验证与演示数据隔离。1.2 另验证了持久 SSH 请求、认证专用链接、取消连接、直接网页入口不检测或自动登录本机客户端、完成通知去重、历史记录过滤，以及历史补齐期间的最新完成事件。真实服务器实测连接与首批读取已通过。不同服务器和未来 Codex 版本仍需验证其具体记录格式。

# 故障排查

## 打开 Tailscale 登录后仍然连接失败

网页登录完成的是账号认证，本机仍需已有可用的 Tailscale 网络。确认自己的电脑和服务器可互相访问、服务器已启用相应 SSH 权限。软件不会安装客户端或修改 Tailscale 规则。Tailscale SSH 使用服务器原用户名与 22 端口；检查本机是否可使用系统 `ssh` 命令。

## 连接超时或一直在补齐

先看界面显示的阶段：连接阶段需要服务器网络、SSH 和 Python 3 可用；连接后的补齐阶段会分批读取历史。可先缩小到近 30 天，等待首批出现，再逐步扩大。首批最多 512 KB，后续继续增量读取，速度受网络和历史规模影响。

## 没有记录

确认 SSH 用户与运行 Codex 的用户相同。默认读取 `~/.codex`，自定义 `CODEX_HOME` 需要填写实际目录，且目录内包含 `sessions`。远程非交互式 SSH 不一定继承终端环境变量。VS Code 扩展或其他用户保存到别处的记录需要连接正确目录。

## 没有完成通知

保持服务窗口运行，在右上角铃铛中启用并测试通知，同时检查 Windows 通知与勿扰设置。只有开始监控之后、日志里出现明确完成事件的对话才通知。历史记录不会补发通知。同步间隔和网络会带来延迟。

## Token 和官方页面不同

本软件汇总所采集日志，不提供官方总账、费用或剩余额度。日志缺失、日期范围、自定义数据目录、重复使用不同来源导入等都会影响结果。缓存和推理 token 不额外重复相加，详见使用手册。

## 升级与卸载

退出服务后备份 `data/`，解压新版本到新目录并将原 `data/` 复制进去。不要用没有保留数据的覆盖操作。卸载时退出程序并删除软件目录即可。

## 提交问题

请提供软件版本、Windows 版本、连接方式、错误文字和经过脱敏的最小示例。不要提交密码、密钥、认证链接、原始数据库或完整工作对话。

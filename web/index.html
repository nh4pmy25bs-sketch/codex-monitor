关于这份记录

本软件读取 Codex 已保存的对话、工具与用量记录，每次同步增量读取，重复同步不会重复计数。

Token 是被采集会话记录里的用量，不等同于账号剩余额度或账单。缓存输入包含在输入 token 中，推理 token 包含在输出中，不额外相加。统计按北京时间归档。

没有用量记录时显示“未记录”；历史不完整、日志格式不兼容时，统计可能不完整。第一条累计计数如果已包含更早用量，只计本次已知用量。

终端的每个字符、输入中的草稿、所有重连提示不一定保存在会话记录中。这里展示已保存的输入、回复和工具结果，不是终端屏幕直播。

“已应用”文件补丁需要有成功结果。通过脚本、命令产生的其他修改，可用“项目当前差异”辅助查看。多人或多个会话共用目录时，无法仅凭目录差异准确归因。

会话长时间没有新记录时显示“状态未知”，不会把日志安静误判成任务完成。本机软件退出后停止同步，服务器原有的 Codex 会话记录仍由 Codex 自己保存。

服务器无需安装软件或开放新端口。采集仅读取 sessions / archived_sessions 和 Git 差异，不读取 Codex 登录凭据。SSH 密码不会持久化。
